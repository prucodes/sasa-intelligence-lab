# Screen map

| Route | Purpose | Primary interactions |
|---|---|---|
| `/` | Open a connected review of rural change, service, delivery and evidence readiness | Choose a subject, narrow an urban programme by district, inspect named ULB shortfalls and their concentration, or open the supporting source |
| `/operational-analytics` | Use retained governed evidence for current operational analysis without creating route sprawl | Switch between Collection, Sanitation Delivery, Processing Infrastructure, and Swachh Outcomes tabs; separate ULB procurement from district collection assets; review legacy-waste balances or the facility registry; inspect latest-period calculations and source-grain tables |
| `/environment` | Read retained waste, wastewater and green-asset evidence as a physical ledger, then keep screening scenarios visibly apart from reported quantities | Switch between the physical ledger, carbon scenarios, inventory gaps and the evidence-to-action pathway; inspect each line's period, repeat handling and boundary; read every scenario assumption with its source; distinguish supported sanitation actions from the wider inventory required for a carbon-neutrality claim |
| `/gap-radar` | Display eligible demo fixtures in four quadrants in DEMO mode; in SAMPLE mode show the unmet activation gates and the crosswalk workbench that makes the first of them workable | Select a marker (DEMO); review candidate ULB matches against the anchor registry and record Approve / No match / Defer decisions (SAMPLE) |
| `/diagnostics/:ulbKey` | Explain a selected candidate using reported values, evidence breadth, source grain, formulas/checks, quality flags, raw fields, complete-snapshot provenance, and every exact normalized source candidate | Change entity; inspect source-family breadth; open additional exact-name sources; select any retained source record in the Evidence Inspector |
| `/data-readiness` | Separate authorization, documented integrations, compact and full coverage, retrieved periods, source reconciliation, join readiness, and scoring eligibility | Switch Catalogue/Coverage/Periods/Quality views; inspect 15-source operational breadth; review deterministic reconciliation queues and activation maturity |
| `/goals` | Track stated SASA targets against dated retained readings | Inspect goal status, district shares and expandable source citations; distinguish quantities from rates |
| `/atlas` | Read eight measures across 123 registered ULBs | Choose a measure, district or ULB; inspect held-out reasons; export the filtered evidence brief; read original source ranks without cross-category comparisons |
| `/reconciliation` | Compare retained source revisions | Inspect revised measures, matched populations and evidence boundaries |

The `mode=demo|governed|live` (`sample` remains accepted for old links) query parameter is preserved across navigation. Routes default to Governed data when the parameter is absent or invalid, so an unqualified link never opens on the synthetic Demo fixture. A separate header control switches between light and dark presentation themes without changing data mode or evidence state.

No separate Collection, IHHL, Processing, Coverage, Period, or Dataset Explorer routes exist. These remain internal views within the screen structure above. Environment & Carbon is a route of its own rather than an Operational Analytics tab because that screen carries retained evidence only, while this one deliberately shows a derived estimate layer beside the retained quantities.

The header provides **Ask the evidence**, a side panel (a sheet on phones) with suggested questions, source-linked answers and explicit limits, plus an executive **Brief** loaded on demand. Mobile navigation keeps Overview, Goals, Atlas and Analytics visible; More reveals the other five destinations. Atlas links preserve the selected measure, district and ULB. Operational Analytics offers only periods retained for the selected programme and labels its headline accordingly.
